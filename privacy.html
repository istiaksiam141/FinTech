Privacy and limitations

Plan information in this tab

After a successful calculation, the minimum current plan fields are stored in this browser tab's session storage so the roadmap, stress tests, and report can use the same plan across pages. This includes entered costs, savings, income, expenses, deadline, currency, and exchange-rate source and timestamp. Quote drafts, manual account labels, activity entries, and the report-only name remain only in page memory and are not persisted. Account balances are stored only as unlabelled amounts as part of the savings plan. The saved plan does not include API keys, tokens, or uploaded documents. Use Clear Plan in the navigation to remove it. Closing the tab usually clears session storage.

Storage limitations

Session storage is not encrypted and may be accessible to scripts running on this site's origin. It is tab-scoped browser storage, not an account backup or a secure financial vault. Do not use a shared or untrusted device for sensitive entries.

Online requests

The AI assistant sends only the question you submit to the assistant endpoint; the saved financial profile and quote entries are not included. The API key stays on the server. The exchange-rate endpoint requests Bangladesh Bank reference data. General assistant responses may be unavailable if the server key or provider is unavailable.

Rates, quotes, and payments

No bank account is connected and no transfer is executed. User-entered quotes are not authenticated provider integrations. Bangladesh Bank exchange rates are reference values; actual bank or provider quotes may differ. Confirm terms with your institution and provider.

Projections

Financial projections depend on the amounts, dates, expenses, and rates entered. They assume the stated conditions continue and are not a guarantee of funding, admission, a visa, or a payment outcome.
